# 週報作成マクロ

「年間行事予定（月別のワークシート）」のブックから、週報ブック（`週報R8NEW.xlsm`）の週シートを自動で作るマクロです。

## できること

週の番号を入力するだけで、次の処理をまとめて行います。

1. 「原本」シートをコピーして、その週のシート（例：`34`）を作る。シートがもうあれば、それを使います。
2. 行事予定ブックの `４月`～`３月` シートから、その週の月曜日から31日分を読み取り、G13:L43 に書き込む。

   | 行事予定（月シート） | → | 週報（G13:L43） |
   |---|---|---|
   | A 日 | → | G 日 |
   | B 曜 | → | H 曜 |
   | C 日直 | → | I 日直 |
   | D 校内行事 | → | J 校内行事 |
   | E 校外行事 | → | K 校外行事 |
   | F 提出文書・備考 | → | L 備考（報告等） |

   - 月をまたぐ週や年をまたぐ週（12月→1月）も、次の月のシートから自動で読み取ります。
   - 行事のない日に出る「0」は空欄にします。
3. F12（年度）・H12（月）・F13（週の初日）を設定する。
4. 「今後の予定」欄（D11）から、校内行事のない日の行を省く。
5. 校外行事欄（D4:D8）で、全角スペースを消さずにそのまま表示する（元の原本の数式はスペースを消していました）。
   - 土日の行（9・10行目）は、校内行事・校外行事・備考のうち値のあるものを改行でつないで C 列にまとめ、C:E を結合して左寄せにします（事前入力 I9:K10 の内容も含みます）。
6. 行の高さを調整する。
   - 対象は4～8行目（月～金、A～E 列）、9・10行目（土日、結合した C:E）、11行目の「今後の予定」（D11）です。
   - 内容がすべて見える高さにそろえます。原本の高さより低くはしません。
   - 行の高さの上限（409 ポイント）でも入りきらないセルは、0.5 ポイントずつ（最小 6 ポイントまで）フォントを小さくします。
   - 画面と印刷の差で切れないように、測った高さに1割の余裕を持たせています。

「お知らせ・お願い」欄や「事前入力内容」（G4:K10）は書き換えません。

## 取り込み方（最初の1回だけ）

コードを貼り付ける方法がいちばん確実です。

1. `週報R8NEW.xlsm` を開き、`Alt` + `F11` を押して VBA の画面を開く。
2. 以前に取り込んだ「週報作成マクロ」（または Module1 など）があれば、右クリック →［削除］（エクスポートは［いいえ］）。
3. メニューの［挿入］→［標準モジュール］。
4. `週報作成.txt` をメモ帳で開き、すべて選択（`Ctrl`+`A`）してコピーし、右側の白い画面に貼り付ける。
5. メニューの［デバッグ］→［VBAProject のコンパイル］を押す。何も表示されなければ成功です。
6. VBA の画面を閉じて、上書き保存する。

（`週報作成.bas` は［ファイル］→［ファイルのインポート］で取り込む用です。**メモ帳で開いて貼り付けないでください**。1行目の `Attribute` がエラーになります。）

ショートカットキーを使いたいときは、`Alt` + `F8` →「週報作成」→［オプション］で `Ctrl` + `Shift` + `W` などを設定してください。

`Ctrl` + `Shift` のショートカットで実行すると、Excel はファイルを開いた直後にマクロを止めてしまうことがあります（Excel の既知の不具合）。このマクロは、続きの処理を予約してから行事予定ファイルを開くため、止まっても週報作成まで進みます。

## 使い方

1. `週報R8NEW.xlsm` を開く（行事予定ブックは開いていても、閉じていても構いません）。
2. `Alt` + `F8` →「週報作成」→［実行］（ショートカットキーを設定した場合はそのキー）。
3. 週の番号を入力する。最初から「記入済みの最後の週の次」の番号が入っています。
4. 週の開始日（月曜日）を確認する。前の週の開始日＋7日が入っています。
   - そのままでよければ［OK］。
   - 夏休み明けなどで違うときは、正しい日付（例：`2026/8/31` や `8/31`）に直して［OK］。
   - 月曜日以外の日付を入れたときは、その週の月曜日にそろえます。
5. 初回だけ行事予定ファイルを選ぶ画面が出ます。2回目からは同じファイルを自動で開きます。
6. できあがったシートの「お知らせ・お願い」欄を書き足し、いつもどおり `Ctrl` + `Shift` + `P` で印刷します。

## 追加情報（校内行事の名称に情報を足す・置き換える）

週報ブックに「追加情報」シートを作り、A列にキーワード、B列に編集後の文字列を書きます（1行目は見出し）。週報を作るとき、校内行事にキーワードがあれば自動で編集します。

| A列 キーワード | B列 編集後 | 結果の例 |
|---|---|---|
| `ALT＊` | `ALT＊（②３年③４年④６年⑤５年）` | ALT⑥ → ALT⑥（②３年③４年④６年⑤５年） |
| `職員会議＊` | `職員会議＊（15:30～図書室）` | 職員会議⑪ → 職員会議⑪（15:30～図書室） |
| `SC` | `SC（スクールカウンセラー）` | SC → SC（スクールカウンセラー） |

- キーワードの「＊」には番号（数字・全角数字・丸数字）が当てはまり、編集後の「＊」に同じ番号が入ります。
- 番号がないものは対象外です（「ALTとの打合せ」は `ALT＊` に一致しません）。
- 行事名の先頭から一致したものだけが対象です（「代表委員会」は `委員会＊` に一致しません）。
- キーワードの直後に別の文字が続くものは対象外です（「＊ALT３校時⇔５校時」は一致しません）。
- すでに編集済みのものに、二重に付け足すことはありません。
- 上の行のキーワードから順に当てはめます。

「追加情報」シートを直したあとは、週のシートを表示して `Alt` + `F8` →「追加情報反映」→［実行］で反映し直せます。シートがないときに実行すると、見出しと例（ALT＊）を入れた「追加情報」シートを作ります。

## 行の高さだけを調整し直す

お知らせ欄や行事を手で書き足したあとは、その週のシートを表示して `Alt` + `F8` →「行の高さ調整」→［実行］で、行の高さとフォントを調整し直せます。

## 注意

- 開始日は、前の番号の週シートから計算します。その週が空のひな形なら、さらに前の記入済みの週から計算します。
- 行事予定ブックの内容を直したときは、もう一度同じ週番号で実行すれば読み直せます（上書きの確認が出ます）。
- 「今後の予定」欄を元の表示のまま使いたいときは、マクロ先頭の `TIDY_SCHEDULE` を `False` にしてください。
- 来年度も使えます。行事予定ブックの月シート名（`４月`～`３月`）と列の並びが同じなら、そのまま動きます。

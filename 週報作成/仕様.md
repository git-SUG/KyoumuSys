# 週報自動作成 仕様

週報ブック（`週報R8NEW.xlsm`）のマクロ「週報作成」が、年間行事予定ブックの内容から、1週間分の週シートを作るときの仕様です。使い方・取り込み方は [README.md](README.md) を参照してください。

## 1. 全体の流れ

1. 作成する週の番号を入力する（既定値は、記入済みの最後の週の次）。
2. 週の開始日（月曜日）を確認する（既定値は、前の週の開始日＋7日）。
3. 行事予定ブックを開く（開いていればそのまま使う。初回だけファイルを選ぶ）。
4. 週シート（「原本」のコピー。すでにあればそれを使う）の次の欄に、内容を**直接**書き込む。
   - 週の期間（E2）
   - 月～日の行事欄（A4:E10）
   - 今後の予定（D11）
   - お知らせ欄の「行事・教育課程の反省」の一覧（A11）
5. 行の高さとフォントを調整する。

F～L 列の貼付データ（G13:L43）は使いません。F12（年度）・H12（月）・F13（週の初日）だけは書きます（次の週の開始日の計算と、G4:H10 の日付表示に使うため）。

## 2. 入力データ

### 2.1 行事予定ブック（月シート）

`４月`～`３月` シート（半角数字の `4月` も可）。月の1日が3行目、以降1日1行。月をまたぐ週は、次の月のシートから読む（12月→1月も同じ）。月曜日から**31日分**を読む。

| 列 | 内容 | 読む先 |
|---|---|---|
| C | 日直 | A 列（日付の下） |
| D | 校内行事 | C 列 |
| E | 校外行事 | D 列 |
| F | 提出文書・備考 | E 列 |

- 空の数式が返す「0」やエラー値は空欄にする。
- 校内行事は、続いた全角スペースを1つにし、先頭・末尾の全角スペースと改行を取る。
- 校外行事は、詳細の括弧の前で改行する（§4.4）。

### 2.2 週報ブック内のシート

| シート | 使い方 |
|---|---|
| 原本 | 週シートのひな形。セルの書式・行の高さ・図形の基準。 |
| 国民の祝日 | A 祝日名、B 日付、C 意味（2行目から）。祝日の行の表示（§4.6）と、反省欄から祝日を除く処理に使う。 |
| 追加情報 | A キーワード、B 編集後（§5）、C メモ、D 反省欄から除く言葉（§7）。1行目は見出し。 |

### 2.3 事前入力内容（G4:K10）

週シートの I～K 列（4～10行目）に手で書いた内容。次の欄の末尾に足す（空なら何もしない）。マクロは書き換えない。

| 事前入力 | 足す先 | 付ける印 |
|---|---|---|
| I 列 | 校内行事（C） | `○` |
| J 列 | 校外行事（D） | なし |
| K 列 | 備考（E） | `〆` |

## 3. 週シートの欄

| 欄 | 内容 |
|---|---|
| E2 | 週の期間（月～金）。`12月14日～12月18日` の形の値。 |
| A4:A10 | 月日＋改行＋日直。例 `12/15`＋改行＋`杉山`。 |
| B4:B10 | 曜日。例 `(月)`。 |
| C4:C8 | 校内行事（月～金）。 |
| D4:D8 | 校外行事（月～金）。 |
| E4:E8 | 備考（報告等）（月～金）。 |
| C9:E10 | 土日。C:E を結合し、校内行事・校外行事・備考をまとめる。 |
| D11 | 今後の予定（8日目以降）。 |
| A11 | お知らせ欄。「※行事・教育課程の反省＞＞＞」の下に行事の一覧を書き出す。 |

A4:E10 と D11 は、数式ではなく**値**で書く。

## 4. 各欄の編集ルール

### 4.1 日直（A 列）

- `月/日` ＋ 改行 ＋ 日直の名前。
- **文字色**: 日直の名前が、同じ日の校外行事（事前入力の校外行事を含む）の「（…）」「(…)」の中にも出てくるときは、A 列のそのセルの文字を**赤**にする。
  - 括弧の中を「、」「・」「，」「：」「／」やスペースで区切り、区切りごとに日直の名前と比べる。
  - 一方がもう一方を含んでいれば一致（部分一致）。ただし、2文字以上のものだけを比べる。
  - 空白と異体字セレクタ（名前の異体字）は無視する。
  - 一致しない日は、原本の A 列の色に戻す。

### 4.2 校内行事（C 列）

月曜日から金曜日（祝日でない日）の C は、次の形で書く。

- 行事ごとに改行して、先頭に `〇` を付ける（元データでは全角スペースが行事の区切り）。
- `＊` で始まる補足には `〇` を付けず、1行ずつ改行する。行事名の途中の `＊` は、前の区切りの扱いで改行する。
- 「〇」の直後では改行しない（例 `〇冬季休業（12/24 ～ 1/5)`）。
- **括弧の中の全角スペースは、行事の区切りにしない**。同じ幅の別の空白に置き換え、1つの行事として扱う（例 `冬季休業（12/24 ～　1/5)`）。括弧は `（` `(` で開き `）` `)` で閉じるもの。閉じていない括弧は何もしない。
- 全体の末尾に改行を1つ付け、事前入力（I 列）があれば `○` を付けてその後に足す。

### 4.3 追加情報の反映

§5 を参照。

### 4.4 校外行事（D 列）

- 全角スペースを消さずにそのまま表示する。
- 時刻・場所などの詳細を表す「（…）」の前で改行し、全角スペース1つ分下げる。対象は、中に全角スペース・`：`・`:`・`、` を含む括弧だけ（「（他校研修）」のように名前の一部の括弧では改行しない）。
- 全体の末尾に改行を1つ付け、事前入力（J 列）があればその後に足す。

### 4.5 備考（E 列）

- 内容が複数あるときは、**改行した内容の先頭にも `〆`** を付ける（空の行は省く）。全角スペースの前にも `〆` を付ける。
- 事前入力（K 列）も同じ書き方で足す。
- **見え消し**: `〆` で始まり、`済` または `済み` で終わる行は、その行全体（`〆` から行末まで）に**取り消し線**を付ける。作り直したときは、いったん取り消し線を外してからやり直す。

### 4.6 土日（9・10行目）

C:E を結合して左寄せ・上揃え・折り返しにし、C に次の順で、値のあるものだけを改行でつないで書く。

1. 校内行事（§4.2 の形、末尾の改行なし）
2. 事前入力の校内行事（`○` 付き）
3. 校外行事
4. 事前入力の校外行事
5. 備考（§4.5 の形）
6. 事前入力の備考

備考の取り消し線（§4.5）は、結合した C でも同じ。

### 4.7 国民の祝日の行

その日の校内行事に、「国民の祝日」シートの A 列の祝日名が含まれるとき（部分一致を含む）、その日の行は次のようにする。月～日のすべての日が対象。

- A～E を、土日と同じ色（原本の土日の行の色）で塗りつぶす。
- C:E を結合して左寄せにする（土日と同じ）。
- C の文字は**太字**にする。
- C の内容は、次の順にする。
  1. 祝日名
  2. 改行
  3. `日付『意味』`（日付は B 列。日付の値なら `11月23日` の形、「1月の第2月曜日」のような文字ならそのまま。意味は C 列。）
  4. その日のほかの内容（祝日の行事は重ねて出さない。ほかの校内行事・事前入力・校外行事・備考を、土日と同じ順で続ける）
- 一致の判定は、全角・半角、大文字・小文字、スペースの違いを区別しない。行事名が祝日名を含む、または（2文字以上の）行事名が祝日名に含まれるとき一致。`＊` で始まる補足は対象外。
- 祝日でない日に戻して作り直したときは、結合・塗りつぶし・太字を原本の状態に戻す。

## 5. 追加情報（校内行事の編集）

「追加情報」シートの A 列にキーワード、B 列に編集後の文字列を書く。週報を作るとき、その週（月～日）の校内行事にキーワードがあれば自動で編集する。

| キーワード | 編集後 | 結果の例 |
|---|---|---|
| `ALT＊` | `ALT＊（②３年③４年④６年⑤５年）` | ALT⑥ → ALT⑥（②３年③４年④６年⑤５年） |
| `職員会議＊` | `職員会議＊（15:30～図書室）` | 職員会議⑪ → 職員会議⑪（15:30～図書室） |
| `SC` | `SC（スクールカウンセラー）` | SC → SC（スクールカウンセラー） |

- キーワードの `＊` には番号（数字・全角数字・丸数字）が当てはまり、編集後の `＊` に同じ番号が入る。番号がないものは対象外。
- 行事名の先頭から一致したものだけが対象。キーワードの直後に別の文字が続くものは対象外。
- すでに編集済みのものに、二重に付け足さない。上の行から順に当てはめる。「編集後」が空欄のキーワードは何もしない。
- 「編集後」の中の全角スペースは、行事の区切りと区別するため、同じ幅の別の空白にして書き込む。
- 今後の予定（D11）は編集しない。
- 単独のマクロ「追加情報反映」は、表示中の週シートの C4:C10 の文字を直接置き換え、反省欄の一覧を書き直し、行の高さを調整し直す。「追加情報」シートがなければ、見出し付きで作る。

## 6. 今後の予定（D11）

月曜日から**8日目以降**（最大31日目まで）の、校内行事のある日だけを書く。

- 1日分の形: `日(曜)＋全角スペース＋行事`。日付が1桁の日は、前に半角スペースを入れる（例 ` 7(月)`、`14(月)`）。
- 行事ごとに `〇` を付け、「＊」で始まる行事には `〇` を付けない。行事名の途中の `＊` は、前に全角スペースを入れる（例 `クラブ③　＊１～３年下校１４：２０`）。
- 8～18日目は、行事の改行を全角スペースにして、1つにつなぐ（`〇A　〇B`）。
- 19日目以降は、改行のまま書く。2行目以降には、次の字下げを付ける。
  - 行頭が `〇`・`＊` の行: 半角スペース10個（日付直後の `〇` の位置の8個＋2個）
  - `〇`・`＊` が付かない行（行事名の途中の改行）: 半角スペース12個
- 日と日の間は改行で区切る。
- マクロ先頭の `TIDY_SCHEDULE` を `False` にすると、行事のない日も書き、元の表示に近い形になる。
- D11 の行事は、追加情報では編集しない。

## 7. お知らせ欄（A11）の行事一覧

「※行事・教育課程の反省＞＞＞」の下に、その週（月～日）の校内行事を `　〇行事名` の形で1行ずつ書き出す。

**書き出さないもの**

- `＊` で始まる補足、行事名の途中の `＊` 以降
- 祝日（「国民の祝日」シートの祝日名と「振替休日」）
- 同じ週の重複
- **「追加情報」シートの D 列（2行目から）の言葉を含む行事**（部分一致）。全角・半角、大文字・小文字、スペースの違いは区別しない。`＊` は任意の文字列として使える。

**書き方**

- 見出しの下の空白だけの行と、前に書き出した `　〇` の行を置き換える。それ以外の内容（【特別日課】など）と事前入力内容は書き換えない。
- 残す行の書式（太字・サイズ・色など）は、書き込み後に付け直す。
- 定例の行事（ALT・職員打合せなど）も書き出すので、不要なものは D 列に書くか、手で消す。

## 8. 行の高さ・フォント

対象は、4～8行目（A～E 列）、9・10行目（A・B 列、結合した C:E）、11行目（A11 と D11）。

- 内容がすべて見える高さにそろえる。原本の高さより低くしない。
- 行の高さの上限（409 ポイント）でも入りきらないセルは、0.5 ポイントずつ（最小 6 ポイントまで）フォントを小さくする。
- 画面と印刷の差で切れないように、測った高さに1割の余裕を持たせる。
- 書式が混ざったセル（A11 など）は、フォントを変えない。
- 行の高さが変わっても、画像（QR コードなど）が原本と同じセルの位置に来るように置き直す。
- 単独のマクロ「行の高さ調整」で、表示中の週シートだけをやり直せる。

## 9. 週番号と開始日

- 開始日は、前の番号の週シートから計算する（さかのぼって、正しい開始日を持つ最初の週を使う）。
- 「記入済みの週」の判定は、F13 に日付が値として入っているか（このマクロで作った週）、または以前の様式で G13:L43 にデータがあるか。原本のひな形は F13 が数式なので、空とみなす。
- すでにある週シートに作り直すときは、上書きの確認を出す。上書きするのは A4:E10・D11・E2 と、A11 の行事一覧。
- 月曜日以外の日付を入れたときは、その週の月曜日にそろえる。

## 10. 補足

- マクロの本体は `週報作成.txt`（コードを貼り付ける用）と `週報作成.bas`（インポートする用）。内容は同じ。
- 行事予定ブックの月シート名（`４月`～`３月`）と列の並びが同じなら、来年度もそのまま使える。
- 次の月のシートが行事予定ブックにないときは、その月の日の内容を空欄にして、完了メッセージでお知らせする。
